# MCP Server: Playwright (via Docker MCP Toolkit)

<tools>
<mcp_server name="playwright">
Playwright is available as an MCP tool via the Docker MCP Toolkit. Use it for end-to-end browser testing of web applications.

When to use Playwright:
- Testing UI flows the same way a real user would (clicking, typing, navigating)
- Verifying that deployed changes work correctly on the staging server
- Checking for visual regressions, broken links, or CORS issues in the browser
